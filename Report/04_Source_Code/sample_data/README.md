# Sample Data

This project does not ship a static sample-data file. Instead, sample
data (1 warden, 4 residents, 5 complaints in varying statuses,
including an overdue example and one with feedback) is generated by
running the seed script:

```bash
cd source_files/server
npm install
npm run seed
```

See `source_files/server/seed/seed.js` for the exact records created,
and the main README's "Seed Database Instructions" section for demo
login credentials.
